Personalized Health is an online information system. The goal of the information system is to allow users to monitor and improve their health, but also to give doctors an original way to communicate with patients and allow them to arrange appointments, read their histories, compare patient examinations through visualizations, etc.

• Scenarios that should be implemented:
Scenario 1: A user needs to be able to see the closest doctors to their home (ideally also using a map), and make an appointment with them (or anyone else they want).
Scenario 2: A user's blood tests can be saved and the system stores them. Then she should show him the exams she has uploaded. It is important for any examination to see if the values are normal or not.
Scenario 3: A user needs to be able to see their history for specific tests (eg cholesterol), compare them, and ideally value visualization is also supported. Also to be able to see the treatments he has received in the same period of time.
Scenario 4: A doctor needs to be able to manage appointments, see a patient's history, eg compare tests, give treatments.
Scenario 5: A patient needs to be able to see what treatment they need to follow at that particular time period.

• The types of users of the application are:
  Central administrator(s)
  Doctors (Pathologists)
  Registered users (patients)
  Visitors

• Basic System Functions:
A. Administrator functions
  View Deleteable Users
  Certification of doctors

B. Doctor Functions
  Create Available appointments
  Access to patient history and their visualization services
  Access to appointments 
  View and visualize exams and patient messages
  Entering new information for a patient

C. Registered User Functions
  Find Doctors by location
  Select, View Appointment 
  View and visualize exams
  Compare user reviews
  Treatment View
  Message to doctor

D. Simple User Functions
  Find and view Doctors 
  System home page
